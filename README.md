# GoLogin Pixelscan Mass Checker

Инструмент для автоматизации массовой проверки цифровых профилей (антидетект-браузеров) на предмет утечек отпечатков и несоответствий параметров.

## Описание

Скрипт подключается к аккаунту GoLogin через официальный Python SDK, получает список доступных профилей, запускает их в headless-режиме и выполняет проверку через сервис Pixelscan.net.

В процессе проверки анализируются следующие параметры:
- Итоговый вердикт сайта (Consistent / Inconsistent).
- Операционная система и версия браузера.
- Геолокация IP-адреса.
- Наличие и статус прокси-сервера.
- Наличие маскировки отпечатка (Fingerprint Masking).

Результаты работы сохраняются в лог-файл и выгружаются в CSV-таблицу для последующей отчетности.

## Функциональные возможности

- **Автоматизация процессов:** Программный запуск и остановка профилей без участия оператора.
- **Обработка динамического контента:** Использование явных ожиданий (WebDriverWait) для корректного сбора данных с Angular-приложения Pixelscan, игнорируя промежуточные состояния загрузки.
- **Оптимизация трафика:** Отключение загрузки изображений в Selenium для ускорения работы и снижения нагрузки на прокси-канал.
- **Формирование отчетности:** Генерация текстового отчета в консоль и выгрузка данных в файл `mass_check_results.csv`.
- **Безопасность и логирование:** Перехват системных логов SDK GoLogin для предотвращения засорения консоли и защита конфиденциальных данных.

## Стек технологий

- Python 3.10+
- GoLogin SDK (управление профилями)
- Selenium WebDriver (парсинг динамического контента)
- webdriver-manager (автоматическая загрузка совместимой версии ChromeDriver)
